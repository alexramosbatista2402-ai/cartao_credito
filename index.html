📌 Atalho no computador

Baixe o atalho e o ícone de cartão de crédito. O atalho abre este mesmo arquivo no seu navegador.

  1. Arraste o atalho baixado para a Área de Trabalho.
  2. Para trocar a imagem: botão direito no atalho → Propriedades → Alterar Ícone → Procurar e escolha o arquivo .ico baixado.
  3. Se mover o arquivo cartao.html de pasta, baixe o atalho de novo.

Dica no Chrome/Edge: menu ⋮ → Salvar e compartilhar → Criar atalho. O ícone do cartão já é usado automaticamente.
