📲 Instalar o app

O navegador não abriu a instalação automática. Isso acontece se o app já está instalado ou se o navegador não permite. Faça assim:

  1. Chrome: clique no ícone de instalar (um monitor com seta) no fim da barra de endereço, ou no menu ⋮ → Salvar e compartilhar → Instalar página como app.
  2. Edge: menu ··· → Aplicativos → Instalar este site como um aplicativo.
  3. iPhone (Safari): botão Compartilhar → Adicionar à Tela de Início.

Se aparecer a opção de criar atalho na Área de Trabalho, deixe marcada. O app abre numa janela própria, com o ícone do cartão.
